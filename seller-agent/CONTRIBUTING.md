# Contributing

## Branching
- Create feature branches from `main`: `feat/*`, `fix/*`, `chore/*`.

## Commit Messages
- Use Conventional Commits (e.g., `feat: add media buy endpoint`).

## Pull Requests
- Ensure CI passes: typecheck, lint, test.
- Add changesets for package changes: `pnpm changeset`.

## Issues
- Use templates and provide clear reproduction steps.
